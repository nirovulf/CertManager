Единичный импорт
Загрузка файлов сертификатов
Можно выбрать несколько файлов одновременно (зажмите Ctrl/Cmd)
Как это работает
  1. Выберите несколько файлов сертификатов (форматы CER, CRT, PEM, DER)
  2. Система автоматически извлечёт данные из каждого сертификата
  3. Сертификаты будут привязаны к сотрудникам по данным из сертификатов
  4. Если сотрудник не найден, он будет создан автоматически
  5. Дубликаты сертификатов будут пропущены
Примечание: Система обрабатывает каждый файл отдельно и показывает общую статистику по итогам импорта.
Поддерживаемые форматы
  • .CER - сертификат в DER или PEM
  • .CRT - сертификат в DER или PEM
  • .PEM - сертификат в PEM
  • .DER - бинарный сертификат
Преимущества
  • Быстрый импорт множества сертификатов
  • Автоматическое создание сотрудников
  • Защита от дубликатов
  • Отчёт об ошибках
